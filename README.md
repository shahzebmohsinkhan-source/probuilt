# ProBuilt Building Remodeling: Website

Static site (HTML/CSS/vanilla JS), no build step.

```
index.html
css/style.css
js/main.js
images/*.jpg
```

## Deploy on GitHub Pages
1. Push these files to the repo root.
2. Settings > Pages > Deploy from branch > `main` / root.

## Notes
- The quote form currently shows a thank-you message only; connect it to a backend (e.g. PHP + PHPMailer) to send emails.
- Swap or add photos in `images/` and update the `IM` / `G` lists at the top of `js/main.js`.
